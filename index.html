Aide · CORE_KANBAN

Organisez vos tâches dans les colonnes, avec les priorités P1, P2 et P3.

  • ? : ouvrir cette aide (hors champ de saisie).
  • Échap : fermer l'aide ou les réglages.
  • Ctrl/⌘ + Entrée : ajouter une tâche depuis le champ de saisie.
  • Vue compacte : déplacer une tâche avec les boutons ← et →, au clavier ou au tactile.
  • Vue détaillée : utiliser les boutons de déplacement et les zones de priorité.
  • Annuler : revenir sur une modification récente ; Restaurer : récupérer une suppression.
