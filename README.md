# Mon Kanban Local

Un gestionnaire de tâches minimaliste de type Kanban qui s'exécute directement dans le navigateur.

## Fonctionnalités
- **Zéro Serveur** : Fonctionne entièrement en local via GitHub Pages.
- **Stockage Persistant** : Utilise le `localStorage` de votre navigateur.
- **Priorités** : Gestion des priorités (Basse, Moyenne, Haute) avec code couleur.
- **Import/Export** : Sauvegardez vos données dans un fichier JSON lisible pour les transférer ou les archiver.

## Utilisation
1. Ajoutez vos notes dans la colonne "À Faire".
2. Déplacez les tâches entre les colonnes via les boutons d'action.
3. Exportez régulièrement vos données pour ne pas les perdre en cas de vidage du cache du navigateur.

## Confidentialité
Vos données ne sont jamais envoyées sur un serveur. Elles restent stockées localement sur votre machine.
